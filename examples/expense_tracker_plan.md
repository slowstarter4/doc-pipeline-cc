# 지출 기록 앱 기획

## 개요

개인이 하루하루 쓴 돈을 간단히 기록하는 앱. 사용자 개념 없이 혼자 쓰는 도구다.

## 1. 지출 기록

1-1. 사용자는 지출을 기록할 수 있다. 기록 시 다음을 입력한다.
- 항목명 (필수)
- 금액 (필수, 0보다 큰 정수)
- 분류 (필수). 분류는 `식비`, `교통`, `쇼핑`, `기타` 네 가지 중 하나만 선택할 수 있다.
- 날짜 (필수, 날짜만 지정하며 시간은 다루지 않는다)

1-2. 사용자는 전체 지출 목록을 조회할 수 있다.

1-3. 사용자는 특정 분류의 지출만 걸러서 조회할 수 있다.

1-4. 사용자는 지출 기록을 삭제할 수 있다. 삭제 시 확인창 없이 즉시 삭제된다.

## 2. 화면 구성

화면은 하나다.

**지출 기록 화면**
지출을 새로 기록하는 입력 영역과, 전체 목록을 보여주는 영역이 함께 있다. 분류 필터로 목록을 거를 수 있고, 각 항목에는 삭제 버튼이 있다.

## 3. 이번 범위에 넣지 않는 것

- 로그인, 사용자 구분
- 지출 수정 (잘못 기록했으면 지우고 다시 기록한다)
- 합계·통계·차트
- 예산 설정, 알림
- 수입 기록 (지출만 다룬다)
