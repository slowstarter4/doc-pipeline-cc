# 디자인 시스템 — Commerce Modernist (토큰 + 컴포넌트 레시피)

출처: claude.ai/design **"Modernist"** 프로젝트(사람이 커머스 운영 백오피스 컨셉으로 생성).
원본은 `design/sources/claude-design/modernist/`(theme.json, styles.css). 이 파일은 그 값을
파이프라인용으로 옮겨 적은 것이다 — **파이프라인이 프롬프트에 싣는 건 이 파일 하나뿐**.

**레이아웃은 여기서 정하지 않는다.** 화면 구성·요소 배치는 화면설계서가 정한다. 이
파일은 톤앤매너 + 컴포넌트 생김새만 고정한다(완성된 페이지를 안 실어 복사를 막는다).

**톤: 라이트 · 각진 스위스 모더니즘 · 강한 rule · Archivo.** 따뜻한 회백색 배경 위
거의 검은 텍스트. **모서리 반경이 전부 0**이고 구분선이 굵다(2px) — 둥글둥글하게
만들면 안 된다. 강조색은 선명한 주홍(#ec3013) 하나뿐이며 아껴 쓴다. 제목은 Archivo
800(아주 굵게) + 자간 -0.015em. 데이터 밀도가 높은 운영 화면용이다.

---

## 색 (라이트)

| 이름 | 값 | 용도 |
|---|---|---|
| bg | `#f3f2f2` | 페이지 배경(따뜻한 회백) |
| surface | `#eae9e9` | 카드·패널·입력 배경 |
| text | `#201e1d` | 본문·제목 |
| text-muted | `rgba(32,30,29,0.55)` | 부가 정보·라벨(= text 55%) |
| divider | `rgba(32,30,29,0.4)` | 구분선·테두리(= text 40%). **진하다 — 흐릿한 회색선 금지** |
| accent | `#ec3013` | 주요 버튼 배경·링크·포커스·선택(주홍) |
| accent-2 | `#e15b47` | 보조 강조 |

**톤 램프** (배지·상태용, 밝은 쪽이 배경·어두운 쪽이 글자):
- neutral: `#f8f4f4`(100) `#eae7e7`(200) `#d7d3d3`(300) `#9b9797`(500) `#7d7979`(600) `#444141`(800) `#2d2b2b`(900)
- accent: `#fff2ef`(100) `#ffe0d9`(200) `#dd2b0f`(600) `#ae1800`(700) `#7c1405`(800)

**상태 색 (파이프라인이 보강한 값 — 원본에는 없다).** Modernist는 mono 팔레트라
강조색이 주홍 하나뿐인데, 이 도메인은 주문·배송·결제·환불 상태가 20종을 넘어 서로
구분돼야 한다. 원본과 같은 밝기대(100=옅은 배경, 800=진한 글자)로 맞춘 값이다:

| 의미 | 배경(100) | 글자(800) |
|---|---|---|
| 대기 / 중립 | `#f8f4f4` | `#444141` |
| 진행중 / 정보 | `#eaf2fb` | `#123a63` |
| 완료 / 성공 | `#eef7ee` | `#1e4620` |
| 보류 / 경고 | `#fdf4e3` | `#5c3d05` |
| 실패 / 거부 | `#fff2ef` | `#7c1405` |
| 취소 / 비활성 | `#eae7e7` | `#7d7979` |

- **실패는 accent 램프를 그대로 쓴다** — 브랜드 강조색이 주홍이라 위험/실패와 의미가 맞다.
- accent(#ec3013)를 넓은 면적에 채우지 않는다. 주요 버튼·선택된 세그먼트·상태 점 정도.
- 취소는 채도를 빼고 흐리게 — 살아있는 상태와 한눈에 갈려야 한다.

## 타이포그래피

- 폰트: `"Archivo", system-ui, sans-serif`. 웹폰트 로드 허용
  (`https://fonts.googleapis.com/css2?family=Archivo:wght@400;600;800&display=swap`).
  제목·본문 모두 Archivo.
- 제목 굵기 **800**, `letter-spacing: -0.015em`, 행간 `1.12`.
- 크기: h1 `42`, h2 `32`, h3 `25`, h4 `20`, h5 `16`, 본문 `15`(행간 1.55), 표 `14`,
  라벨 `12`, 배지·메타 `11`, kicker `10`.
- kicker·테이블 헤더·h6은 `대문자 + letter-spacing 0.08~0.1em` + text-muted.
- **금액 표기**: 우측 정렬 + `font-variant-numeric: tabular-nums`
  (`font-feature-settings: "tnum"`). 정수 원 단위에 천단위 구분 쉼표, 통화기호는
  헤더에 한 번만. 자릿수가 흔들리면 표에서 못 읽는다.

## 간격 (density 1)

스케일(px): `4 / 8 / 12 / 16 / 24 / 32`.
- 관련 요소 사이 `8`, 그룹 사이 `12~16`, 섹션 사이 `24~32`
- 카드 안쪽 여백 `12`, 다이얼로그 `16`
- 표 셀 여백 `8`(행 높이 약 36px) — 한 화면에 20~50행이 놓이는 걸 전제로 한다
- 페이지 좌우 여백 `16`. 콘텐츠 폭은 화면설계서를 따르되, 표 중심 화면은 넓게 쓴다

## 모양·깊이·모션

- **반경 `0`** — 버튼·입력·카드·다이얼로그 전부 각지게. 배지만 아주 살짝(0~2px).
- 구분선: 일반 `1px`, 강조(테이블 헤더 아래·네비 아래·hr) **`2px`**. 색은 divider.
- 그림자: sm `0 1px 2px rgba(45,43,43,0.14)`, md `0 3px 10px rgba(45,43,43,0.16)`,
  lg `0 12px 32px rgba(45,43,43,0.22)`. 카드는 기본적으로 그림자 없이 surface 배경만.
- 포커스: `outline: 2px solid #ec3013; outline-offset: 2px` (입력은 offset 0 + 테두리 accent).
- 전환: `120ms` 정도로 짧게. 배경·테두리 색에만.

## 컴포넌트 레시피

배치는 화면설계서를 따르고, 아래는 각 조각의 생김새만 정한다.

### 버튼
- 공통: `inline-flex`, 세로 가운데, gap `6px`, 글꼴 Archivo **800** `14px`, 행간 1.2,
  여백 `8px 14px`, 반경 `0`, 테두리 `1px solid transparent`.
- **primary**: 배경 `#ec3013`, 글자 `#f3f2f2`. hover `#dd2b0f`, active `#ae1800`.
- **secondary**: 배경 없음, 테두리 divider. hover `rgba(32,30,29,0.07)`, active `0.14`.
- **ghost**: 글자 accent, 좌우 여백 `4px`. hover `rgba(236,48,19,0.10)`.
- **danger**(삭제·취소·환불 거부): primary와 같은 모양이되 배경 `#ae1800`(accent-700).
- disabled: `opacity 0.45` + `cursor: not-allowed`.
- 아이콘 전용 버튼은 `36x36`, 여백 0.

### 입력 / 폼 / 필터
- 라벨: `12px`, 아래 여백 `5px`, 색 `rgba(32,30,29,0.7)`.
- 입력·셀렉트·날짜입력: 최소 높이 `36px`, 여백 `6px 10px`, `14px`, 배경 surface,
  테두리 `1px solid divider`, 반경 `0`, 캐럿 accent.
  hover 시 테두리 `rgba(32,30,29,0.45)`, 포커스 시 테두리 accent.
- **필터 바**: 입력·셀렉트·날짜입력을 한 줄에 gap `8px`로 늘어놓고, 아래에 `2px` rule.
  적용된 필터는 제거 가능한 배지(중립 색 + `×`)로 바 아래에 표시한다.
- **세그먼트 컨트롤**(상태 탭 등): 바깥 테두리 1px, 항목 사이 좌측 테두리 1px,
  항목 여백 `7px 12px` `13px`. 선택된 항목은 배경 accent + 글자 bg.

### 카드
- 배경 surface, 여백 `12px`, 반경 `0`, 기본은 그림자 없음.
- kicker `10px` 대문자 자간 0.1em accent → 제목 Archivo 800 `17px` → 본문 `13px`(불투명도 0.8)
  → 메타 `11px` text-muted 순서.
- 숫자 요약 카드(KPI)는 제목 자리에 금액·건수를 `32px` Archivo 800 + tabular-nums로.

### 상태 배지 (이 시스템의 핵심)
- `inline-flex`, `11px`, 자간 0.02em, 여백 `3px 10px`, 반경 `0~2px`.
- 위 **상태 색** 표의 `배경(100) + 글자(800)` 조합을 쓴다. 테두리 없음.
- 상태 종류가 많으므로 **색만으로 구분하지 않는다** — 배지 안에 상태 이름을 항상 쓰고,
  필요하면 앞에 `6px` 원형 점(글자색과 같은 색)을 둔다.
- 표 안에서는 배지 높이가 행 높이를 늘리지 않게 `line-height: 1.2`.

### 데이터 테이블
- `width:100%`, `border-collapse: collapse`, 본문 `14px`.
- `th`: 좌측 정렬, `11px` 대문자 자간 0.08em, 색 `rgba(32,30,29,0.6)`, 여백 `8px`,
  **아래 테두리 `2px solid divider`**.
- `td`: 여백 `8px`, 아래 테두리 `1px solid divider`.
- 행 hover: `rgba(32,30,29,0.04)`.
- 금액·수량 열은 우측 정렬 + tabular-nums. 상태 열은 배지. 날짜는 `YYYY-MM-DD`.
- 행이 많으므로 줄무늬(zebra)는 쓰지 않는다 — rule만으로 충분하고 더 조용하다.
- 헤더는 스크롤 시 상단 고정(`position: sticky; top: 0; background: bg`).

### 페이지 헤더
- 제목 h2(`32px` Archivo 800) 좌측, 주요 액션 버튼 우측. 아래 `2px` rule.
- 제목 위에 kicker로 상위 맥락(예: 주문 관리)을 대문자로.

### 네비게이션
- 가로 배치, 여백 `12px 16px`, 아래 `2px solid divider`.
- 브랜드는 Archivo 800 `18px` 좌측, 링크 `14px`. 현재 페이지·hover는 accent 색.

### 페이지네이션
- 우측 정렬. `이전 / 페이지 번호 / 다음`을 secondary 버튼 크기로, 현재 페이지만
  배경 accent + 글자 bg. 좌측에 `전체 N건` text-muted `12px`.

### 다이얼로그 (확인·거부 사유 입력 등)
- 배경막 `rgba(45,43,43,0.5)`, 가운데 정렬.
- 본체 폭 `min(440px, 100%)`, 배경 surface, 여백 `16px`, 반경 `0`, 그림자 lg.
- 제목 Archivo 800 `20px` → 본문 `14px`(불투명도 0.85) → 액션 우측 정렬 gap `8px`.

### 빈 상태 / 로딩 / 알림 배너
- 빈 상태: 가운데, 제목 `20px` + 설명 `13px` text-muted + (필요시) primary 버튼 하나.
  표 안이면 전체 열을 병합한 셀에 여백 `32px`.
- 로딩: 스피너 대신 **표 행 모양의 회색 블록**(`#eae7e7`)을 3~5줄 놓고 은은히 점멸.
- 알림 배너: 좌측 `4px` 세로 바 + 옅은 배경. 색은 위 상태 색 표를 따른다
  (성공/정보/경고/실패). 여백 `12px`, 반경 0.

### 접근성·공통
- 텍스트 대비: 본문은 text(#201e1d) on bg — 충분하다. text-muted는 보조 정보에만.
- 상태를 색만으로 전달하지 않는다(배지에 항상 텍스트).
- 포커스 링을 없애지 않는다. 키보드로 표·필터·다이얼로그를 다 쓸 수 있어야 한다.
- 이미지가 있으면 `filter: grayscale(1) contrast(1.08)` — Modernist의 흑백 처리.
