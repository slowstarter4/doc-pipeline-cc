# 디자인 시스템 — Modern Minimal (프리셋)

톤: **모노톤 · 순백 배경 · 그림자 없음 · 넉넉한 여백.** 색을 거의 안 쓴다 -
거의 흑백에 강조색 하나만 절제해서 쓰고, 위계는 색이 아니라 굵기·크기·여백으로
만든다. 카드도 테두리 대신 여백과 구분선만으로 나뉘는 경우가 많다(Linear/Vercel
계열의 절제된 프로덕트 UI).

**레이아웃은 여기서 정하지 않는다.** 화면 구성·배치는 화면설계서가 정한다.

---

## 색

**중립(neutral) 램프** — 이 프리셋의 주력. 대부분의 UI가 이 램프만으로 완성된다:

| 이름 | 값 | 용도 |
|---|---|---|
| bg | `#ffffff` | 페이지 배경(순백) |
| surface | `#ffffff` | 카드·패널·입력 배경(배경과 동일 - 구분은 테두리로만) |
| surface-2 | `#fafafa` | 아주 옅은 강조(테이블 헤더, hover) |
| border | `#e5e5e5` | 구분선·테두리(옅게) |
| border-strong | `#d4d4d4` | 입력 테두리 |
| text | `#0a0a0a` | 제목·본문(거의 검정) |
| text-muted | `#737373` | 부가 정보·라벨 |
| text-faint | `#a3a3a3` | 플레이스홀더·아주 약한 메타 |

**강조 하나만**: 색은 이거 하나로 절제한다. 넓은 면적에 쓰지 않는다.

| 이름 | 값 | _bg(옅음) | 용도 |
|---|---|---|---|
| accent | `#171717` | `#f5f5f5` | 주요 버튼·선택·포커스(색이 아니라 거의 검정) |
| accent-hover | `#000000` | — | accent hover |

**의미(semantic)** — 배지·경고에만, 채도를 낮춰 튀지 않게:

| 이름 | 값 | _bg(옅음) | 용도 |
|---|---|---|---|
| success | `#166534` | `#f0fdf4` | 완료·정상 |
| warning | `#92400e` | `#fffbeb` | 주의·대기 |
| danger | `#991b1b` | `#fef2f2` | 오류·삭제·거부 |

- accent(거의 검정)를 주요 동작 하나에만. 페이지당 강조색 사용은 최소로.
- 상태 배지도 채도 낮은 색 + 텍스트 라벨로 - 원색 배지 금지.

## 타이포그래피

- 폰트: `Inter, -apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif`
  (Inter는 Google Fonts 로드 허용, 실패 시 시스템 폰트로 자연스럽게 폴백).
- 스케일: `12 / 13 / 14 / 15 / 18 / 24 / 32`px. 이 밖의 크기는 안 쓴다.
  - 페이지 제목 `32/600`, letter-spacing `-0.02em`
  - 섹션/카드 제목 `18/600`, letter-spacing `-0.01em`
  - 본문 `14/400`, 행간 `1.6`(미니멀 톤은 행간을 넉넉히 - 밀도보다 여백)
  - 라벨·메타 `13/500`, text-muted
  - 배지·아주 작은 메타 `12/500`
- 굵기는 `400/500/600`만 쓴다. **700(bold) 쓰지 않는다** - 미니멀 톤은 굵기
  대비를 좁게 가져간다(400 vs 600 정도로만 위계를 준다).
- 숫자 정렬 열엔 `font-variant-numeric: tabular-nums`.

## 간격

`4px` 배수 스케일: `4 / 8 / 12 / 16 / 24 / 32 / 48 / 64`.

- **미니멀 톤의 핵심은 여백이다** - 요소 사이를 아끼지 않는다. 관련 요소
  사이 `12px`, 그룹 사이 `24~32px`, 섹션 사이 `48px`.
- 카드 안쪽 여백 `32px`(다른 프리셋보다 넉넉하게).
- 페이지 좌우 여백 `24px`, 콘텐츠 최대 너비 `720px` 가운데 정렬(좁고 읽기
  편하게 - 데이터 밀집형이 아니라 여백 중심).
- 위아래 쌓이는 요소는 `gap`(flex/grid)으로.

## 깊이·모양·모션

- 반경: 버튼·입력 `6px`, 카드·패널 `10px`, pill(배지) `999px`. 각지지도
  둥글지도 않은 절제된 반경 - 큰 반경(16px+)이나 반경 0은 쓰지 않는다.
- 테두리: `1px solid border`(#e5e5e5, 아주 옅게). 입력은 `border-strong`.
- **그림자를 쓰지 않는다.** 카드·패널은 `1px border`만으로 분리한다(그림자
  없는 완전한 flat). 딱 하나 예외: 모달·팝오버처럼 페이지 위에 뜨는 레이어만
  `shadow-float` = `0 8px 24px rgba(0,0,0,0.08)`.
- 포커스 링: `0 0 0 3px rgba(23,23,23,0.12)`(accent 12%, 아주 옅게). outline
  대신 box-shadow.
- 전환: `transition: 120ms ease`(background/border/box-shadow만 - transform
  같은 튀는 모션은 안 쓴다).
- 배경 그라데이션·이미지·패턴 없음. 색은 위 팔레트에서만.

## 컴포넌트 레시피

각 컴포넌트는 아래 스펙 **그대로** 만든다. 배치는 화면설계서를 따른다.

### 버튼
높이 `40px`, 좌우 여백 `20px`(넉넉하게), `radius 6px`, 글자 `14/500`,
`transition 120ms`. 누를 때 별도 transform 없음(미니멀 - 배경색 변화만).
- **primary**: 배경 `accent`(#171717), 흰 글자. hover 배경 `accent-hover`(#000).
  그림자 없음.
- **secondary**: 배경 투명, `1px border-strong`, 글자 `text`. hover 배경 `surface-2`.
- **ghost**: 투명 배경, 글자 `text-muted`, 테두리 없음. hover 배경 `surface-2`.
- **danger**: 투명 배경, 글자 `danger`. hover 배경 `danger_bg`.
- 작은 버튼(테이블 행 등): 높이 `32px`, 좌우 `14px`, 글자 `13/500`.
- disabled: opacity `0.4`, 커서 not-allowed.
- 포커스 시 포커스 링(아주 옅게).

### 입력 / 폼
- 필드: 라벨(위, `13/500` text-muted) → 인풋 → 헬퍼/에러(아래, `12`), `gap 8px`.
- 인풋 높이 `40px`, 좌우 `14px`, `radius 6px`, `1px border-strong`, 배경
  `surface`, 글자 `14`. 그림자 없음(순수 아웃라인).
  - focus 시 테두리 `accent` + 옅은 포커스 링.
  - 에러: 테두리 `danger`, 헬퍼 텍스트 `danger`(`12`).
- 폼 필드 사이 `gap 20px`(넉넉). 제출 버튼은 폼 하단, 왼쪽 정렬(미니멀 톤은
  우측정렬 대신 본문 흐름과 같은 왼쪽 정렬을 선호).

### 카드 / 패널
`surface` 배경, `radius 10px`, `1px border`(#e5e5e5), **그림자 없음**, 안쪽
여백 `32px`.
- 헤더가 있으면: 제목(`18/600`) + 선택적 부제(`13` text-muted), 아래 `1px
  border` 구분선, 본문과 `20px` 간격.
- 클릭 가능한 카드는 hover에서 그림자를 더하지 않고 **테두리만** `border-strong`으로
  진하게(미니멀은 hover도 절제).

### 목록 / 테이블
- **목록 행**: 좌우 여백 `16px`, 위아래 `16px`(넉넉), 아래쪽에만 `1px border`
  구분선(마지막 행 없음). hover 시 배경 `surface-2`(아주 옅게). 주 텍스트
  (`14/500`) 왼쪽, 메타·상태·액션 오른쪽.
- **테이블**: 헤더 행 배경 없음(`bg`와 동일) + 아래 `1px border-strong` 구분선
  하나, 글자 `12/500` text-muted, letter-spacing `0.02em`(대문자 강제 안 함 -
  미니멀은 대문자보다 여백으로 구분). 셀 여백 `14px 16px`, 행 사이 `1px border`,
  행 hover 배경 `surface-2`. 숫자 열 tabular-nums 우측 정렬.

### 상태 배지 (pill)
높이 `22px`, 좌우 `10px`, `radius 999px`, 글자 `12/500`. 채도 낮은 톤:
- 정상·완료 = `success_bg` 배경 + `success` 글자
- 주의·대기 = `warning_bg` 배경 + `warning` 글자
- 오류·거부 = `danger_bg` 배경 + `danger` 글자
- 중립·기본 = `surface-2` 배경 + `text-muted` 글자(테두리 `1px border` 추가 -
  배경이 거의 흰색이라 구분이 필요)
색만으로 구분하지 않는다 - 배지 안에 항상 라벨 텍스트.

### 페이지 헤더
제목(`32/600`) + 선택적 부제(`14` text-muted) 왼쪽, 주요 액션 버튼 오른쪽.
아래 `32px` 간격(다른 프리셋보다 넉넉).

### 빈 상태 / 로딩 / 알림
- 빈 목록: 가운데 정렬, `text-muted`로 "아직 없습니다" + 선택적 액션 버튼.
  여백 아주 넉넉히(`64px 24px`).
- 로딩: "불러오는 중…" 텍스트(text-muted). 스피너 없음.
- 알림/에러 배너: 그림자·굵은 테두리 없이, 옅은 `의미색_bg` 배경 + 텍스트만
  (좌측 굵은 테두리도 생략 - 미니멀은 색 블록보다 여백으로 강조). 성공은
  success, 오류는 danger.

### 접근성·공통
- 상태·정보를 색만으로 전달하지 않는다(항상 텍스트 동반) - 강조색을 극도로
  절제하는 톤이라 이 원칙이 특히 중요하다.
- 대화형 요소는 키보드 포커스가 보여야 한다(포커스 링).
- 대비: text(#0a0a0a)가 배경(#ffffff) 대비 충분히 진하다. text-muted도 AA
  기준을 만족하는 선에서만 옅게(#737373 이하로 더 흐리게 하지 않는다).
